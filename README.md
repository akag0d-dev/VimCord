# 🎙️ VimCord

**VimCord** — это полнофункциональный прототип легковесного VoIP и текстового мессенджера в стиле Discord, разработанный на **Python** и **pywebview**.

Проект поддерживает постоянное хранилище на **SQLite**, систему регистрации и авторизации с хешированием паролей, управление аккаунтом, списки друзей с заявками, инвайты на серверы по кодам, **демонстрацию экрана (Screen Sharing)**, а также персональные прямые звонки 1-на-1 и голосовые каналы.

---

## ✨ Основные возможности

- **Постоянное хранение данных (SQLite встроен в Python)**:
  - Вся переписка (в текстовых каналах и личных диалогах) надежно сохраняется в локальной базе данных `vimcord_data.db`.
  - При переключении между диалогами или перезапуске клиента история переписки мгновенно подгружается.
- **Регистрация и безопасность**:
  - Вкладки «Вход» и «Регистрация».
  - Безопасное хеширование паролей (`pbkdf2_hmac` с уникальной солью для каждого аккаунта).
  - Автозапоминание последнего сервера, портов и логина в локальный конфиг.
- **Управление аккаунтом**:
  - Смена отображаемого имени.
  - Персональный статус / био (например: *«Кодит на Python»*, *«Занят»*).
  - Выбор фирменного цвета аватара из палитры Discord.
  - Смена пароля прямо в настройках.
- **Друзья и заявки**:
  - Вкладка «Друзья»: В сети, Все, Ожидание входящих/исходящих заявок.
  - Поиск пользователя по никнейму и отправка заявки в друзья.
  - Кнопки быстрого звонка 📞 и перехода в чат 💬.
- **Инвайты на серверы**:
  - Генерация коротких кодов приглашений (например, `VC-A4F2`) в один клик.
  - Присоединение к серверам по коду инвайта через кнопку `+`.
- **Демонстрация экрана (Screen Sharing)**:
  - Трансляция экрана в голосовом канале или личном звонке нажатием кнопки **«🖥️ Экран»**.
  - Окно видеострима у участников с возможностью масштабирования.
- **Голосовая связь (VoIP)**:
  - 24 kHz HD Audio, 20 мс буфер.
  - Детекция активности голоса (VAD) с анимированной **зеленой подсветкой аватара говорящего** в реальном времени.
  - Безопасное программное микширование нескольких говорящих без искажений (`numpy.clip`).
  - Быстрые кнопки **Mute** (микрофон) и **Deafen** (наушники).
  - Процедурный синтез звуков звонка и оповещений (без внешних аудио-файлов).
- **Прямые звонки 1-на-1 (Direct Calls)**:
  - Всплывающее окно входящего звонка с мелодией вызова: «Принять 📞» или «Отклонить ❌».
  - Панель активного звонка с таймером разговора и кнопкой сброса.
- **Современный UI на pywebview**:
  - Полный перенос графического интерфейса на **pywebview** (HTML5, CSS3, ES6) с точным сохранением оформления Discord (Dark, AMOLED Midnight, Light темы).
- **Вставка из буфера обмена (Ctrl + V)**:
  - Мгновенное прикрепление скриншотов (из Ножниц / `Win+Shift+S`) и файлов прямо в поле ввода чата.
- **Глобальный Push to Talk (PTT)**:
  - Работает поверх любых окон и в полноэкранных играх.
  - Распознавание клавиш по виртуальным кодам (не зависит от языка/раскладки клавиатуры).
  - Поддержка связывания с любыми клавишами и кнопками мыши (`Mouse 3`, `Mouse 4`, `Mouse 5`).
- **Асинхронная передача файлов**:
  - Отправка вложений (до 25 МБ) происходит в фоновом потоке без фризов и зависания UI.
- **Мультиязычный системный трей**:
  - Динамическая локализация контекстного меню трея (Русский / English) и индикатор активности речи.
- **Настройки звука**:
  - Выбор микрофона и динамиков.
  - Регуляторы громкости микрофона и звука (до 200%).
  - Проверка микрофона в реальном времени со шкалой уровня.

## 🚀 Быстрый запуск на локальной машине

### 1. Установка зависимостей клиента
```bash
pip install -r requirements.txt
```
*(Клиент требует: `pywebview`, `sounddevice`, `numpy`, `pystray`, `pynput`, `mss`, `Pillow`)*

### 2. Запуск сервера
```bash
python run_server.py
```

### 3. Запуск клиентов
```bash
python run_client.py
```
*(Для тестирования можно запустить два окна клиента с разными аккаунтами)*

## 🌐 Установка и запуск на VPS сервере (Linux / Ubuntu / Debian)

> [!NOTE]
> **Серверная часть не требует GUI библиотек (PyQt6) или аудиодрайверов (`sounddevice`)!**
> Сервер написан исключительно на стандартной библиотеке Python 3 (`asyncio`, `socket`, `sqlite3`, `json`, `struct`), поэтому потребляет минимум памяти (< 30 МБ) и запускается на любом чистом Linux VPS.

### Шаг 1. Подключение к VPS и клонирование
```bash
ssh root@IP_ВАШЕГО_VPS
git clone https://github.com/akag0d-dev/VimCord.git
cd VimCord
```

### Шаг 2. Открытие портов в фаерволе
Сервер использует **TCP 9988** для команд и **UDP 9989** для голоса и видеопотока экрана:
```bash
sudo ufw allow 9988/tcp
sudo ufw allow 9989/udp
sudo ufw reload
```

### Шаг 3. Запуск службы в фоне (systemd)
Создайте файл службы:
```bash
sudo nano /etc/systemd/system/vimcord.service
```

Вставьте следующее содержимое:
```ini
[Unit]
Description=VimCord Server
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/VimCord
ExecStart=/usr/bin/python3 /root/VimCord/run_server.py --host 0.0.0.0 --tcp-port 9988 --udp-port 9989
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Активируйте и запустите службу:
```bash
sudo systemctl daemon-reload
sudo systemctl enable vimcord
sudo systemctl start vimcord
```

## 📁 Структура проекта

```
VimCord/
├── run_server.py               # Быстрый запуск сервера
├── run_client.py               # Быстрый запуск клиента
├── requirements.txt            # Зависимости для клиента
├── README.md                   # Документация и инструкция к VPS
├── vimcord/
│   ├── common/
│   │   ├── protocol.py         # Сериализация пакетов TCP (JSON) и UDP (аудио/видео)
│   │   └── audio_codec.py      # VAD, вычисление RMS, микшер и защита от клиппинга
│   ├── server/
│   │   ├── db.py               # SQLite база данных (пользователи, история, друзья, инвайты)
│   │   ├── server_state.py     # Модель комнат, каналов, пользователей, звонков
│   │   ├── tcp_server.py       # TCP сервер управления и сигналинга
│   │   ├── udp_server.py       # Низколатентный UDP роутер голоса и экрана
│   │   └── main.py             # Точка входа сервера
│   └── client/
│       ├── audio/
│       │   ├── audio_manager.py # Захват и воспроизведение через sounddevice
│       │   └── ringtone.py      # Процедурная генерация мелодий вызова
│       ├── video/
│       │   └── screen_share.py # Захват экрана через mss и JPEG сжатие
│       ├── network/
│       │   ├── tcp_client.py   # Неблокирующий TCP клиент и сигналы
│       │   └── udp_voice.py    # Поток UDP передачи/приема аудио и экрана
│       ├── input/

│       ├── tray/

│       └── web/
│           ├── index.html      # Интерфейс приложения в стиле Discord
│           ├── css/style.css   # Стили (Dark, AMOLED, Light темы)

└── tests/                      # Автоматические тесты

    ├── test_audio.py
    ├── test_db.py
    ├── test_pywebview_features.py
    └── test_server_integration.py
```
