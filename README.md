# 🎙️ VimCord

**VimCord** — это прототип легковесного VoIP и текстового мессенджера в стиле Discord, разработанный на **Python** и **PyQt6**.

Проект поддерживает раздельные комнаты (серверы), текстовые и голосовые каналы с несколькими участниками, а также **персональные прямые звонки 1-на-1** с интерфейсом входящего вызова («Принять» / «Отклонить»).

---

## ✨ Основные возможности

- **Архитектура Клиент-Сервер**:
  - **TCP (порт 9988)**: Управление комнатами, каналами, авторизация, обмен текстовыми сообщениями, сигналинг вызовов.
  - **UDP (порт 9989)**: Сверхнизколатентная передача звука (24 kHz HD, 20 мс буфер).
- **Комнаты и каналы**:
  - Создание собственных комнат (серверов).
  - Создание текстовых (`#`) и голосовых (`🔊`) каналов внутри комнат.
  - Список участников в каждом голосовом канале.
- **Голосовая связь (VoIP)**:
  - Детекция активности голоса (VAD) с настраиваемым порогом чувствительности.
  - **Анимированная зелёная подсветка** аватара при речи в реальном времени.
  - Безопасное программное микширование нескольких говорящих без клиппинга (`numpy.clip`).
  - Быстрые кнопки **Mute** (микрофон) и **Deafen** (наушники).
  - Процедурный синтез звуков звонка и оповещений (без внешних аудио-файлов).
- **Прямые звонки 1-на-1 (Direct Calls)**:
  - Вызов любого пользователя онлайн нажатием кнопки 📞.
  - Всплывающее окно входящего звонка с мелодией вызова: «Принять 📞» или «Отклонить ❌».
  - Панель активного звонка с таймером разговора и кнопкой сброса.
- **Текстовый чат**:
  - Обмен сообщениями в текстовых каналах комнат и в личных сообщениях (ЛС).
- **Настройки звука**:
  - Выбор микрофона и динамиков.
  - Регуляторы громкости микрофона и звука (до 200%).
  - Проверка микрофона в реальном времени (индикатор уровня и сквозной тест звука).

## 🚀 Быстрый запуск на локальной машине

### 1. Установка зависимостей клиента
```bash
pip install -r requirements.txt
```
*(Зависимости: `PyQt6`, `sounddevice`, `numpy`)*

### 2. Запуск сервера
```bash
python run_server.py
```

### 3. Запуск клиентов (для тестирования можно открыть 2 окна)
В первом терминале:
```bash
python run_client.py --user Alice --auto
```
Во втором терминале:
```bash
python run_client.py --user Bob --auto
```

## 🌐 Установка и запуск на VPS сервере (Linux / Ubuntu / Debian)

> [!NOTE]
> **Серверная часть не требует GUI библиотек (PyQt6) или аудиодрайверов (`sounddevice`)!**
> Сервер написан исключительно на стандартной библиотеке Python 3 (`asyncio`, `socket`, `json`, `struct`), поэтому потребляет минимум оперативной памяти (< 30 МБ) и запускается на любом чистом Linux VPS.

### Шаг 1. Подключение к VPS и клонирование репозитория
```bash
# Подключитесь по SSH к вашему серверу:
ssh root@YOUR_SERVER_IP

# Клонируйте репозиторий:
git clone https://github.com/akag0d-dev/VimCord.git
cd VimCord
```

### Шаг 2. Открытие портов в фаерволе
Сервер использует **TCP 9988** для команд и **UDP 9989** для голоса:
```bash
# Для UFW:
sudo ufw allow 9988/tcp
sudo ufw allow 9989/udp
sudo ufw reload

# Для iptables (если UFW не используется):
# sudo iptables -A INPUT -p tcp --dport 9988 -j ACCEPT
# sudo iptables -A INPUT -p udp --dport 9989 -j ACCEPT
```

### Шаг 3. Запуск сервера

#### Вариант А: Быстрый запуск в фоне (через tmux или screen)
```bash
# Установка screen (если еще не установлен):
sudo apt update && sudo apt install -y screen

# Запуск в отдельной сессии:
screen -S vimcord
python3 run_server.py
# Чтобы свернуть сессию, нажмите Ctrl+A, затем D
# Чтобы вернуться в сессию: screen -r vimcord
```

#### Вариант Б: Запуск как фоновая системная служба (systemd)
Создайте файл службы:
```bash
sudo nano /etc/systemd/system/vimcord.service
```

Вставьте следующее содержимое (замените `/root/VimCord` на ваш путь к папке):
```ini
[Unit]
Description=VimCord VoIP & Chat Server
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/VimCord
ExecStart=/usr/bin/python3 /root/VimCord/run_server.py --host 0.0.0.0 --tcp-port 9988 --udp-port 9989
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Сохраните (`Ctrl+O`, Enter, `Ctrl+X`) и активируйте службу:
```bash
sudo systemctl daemon-reload
sudo systemctl enable vimcord
sudo systemctl start vimcord

# Проверка статуса:
sudo systemctl status vimcord
```

### Шаг 4. Подключение клиентов к вашему VPS
На компьютерах пользователей:
1. Запустите клиент:
   ```bash
   python run_client.py
   ```
2. В окне входа укажите:
   - **Имя пользователя**: Любой ник (например, `User1`)
   - **Адрес сервера**: IP-адрес вашего VPS (например, `194.87.xxx.xxx`)
   - **TCP Порт**: `9988`
   - **UDP Порт**: `9989`
3. Нажмите **«Подключиться»**!

## 📁 Структура проекта

```
VimCord/
├── run_server.py               # Быстрый запуск сервера
├── run_client.py               # Быстрый запуск клиента
├── requirements.txt            # Зависимости для клиента
├── README.md                   # Документация и инструкция к VPS
├── vimcord/
│   ├── common/
│   │   ├── protocol.py         # Сериализация пакетов TCP (JSON) и UDP (бинарный)
│   │   └── audio_codec.py      # VAD, вычисление RMS, микшер и защита от клиппинга
│   ├── server/
│   │   ├── server_state.py     # Модель комнат, каналов, пользователей, звонков
│   │   ├── tcp_server.py       # TCP сервер управления и сигналинга
│   │   ├── udp_server.py       # Низколатентный UDP роутер голоса
│   │   └── main.py             # Точка входа сервера
│   └── client/
│       ├── audio/
│       │   ├── audio_manager.py # Захват и воспроизведение через sounddevice
│       │   └── ringtone.py      # Процедурная генерация мелодий вызова
│       ├── network/
│       │   ├── tcp_client.py   # Поток TCP клиента и сигналы Qt
│       │   └── udp_voice.py    # Поток UDP передачи/приема аудио
│       └── ui/
│           ├── styles.py       # Discord-стиль оформления (QSS)
│           ├── login_dialog.py # Диалог подключения
│           ├── server_nav.py   # Левая панель с иконками серверов
│           ├── channel_list.py # Боковая панель каналов / друзей
│           ├── user_panel.py   # Нижняя карточка профиля (Mute, Deafen, Настройки)
│           ├── chat_view.py    # Текстовый чат
│           ├── voice_view.py   # Сцена голосового канала с анимацией речи
│           ├── call_overlay.py # Окно входящего звонка и плашка активного вызова
│           ├── settings_dialog.py # Окно настроек аудиоустройств и тест микрофона
│           └── main_window.py  # Главное окно приложения
└── tests/                      # Автоматические тесты
    ├── test_protocol.py
    ├── test_audio.py
    └── test_server_integration.py
```
